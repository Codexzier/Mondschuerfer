Der Server schreibt jede Minute eine Zeile ins Lastprotokoll, mit den Höchstwerten dieser Minute. Eine Minute gilt als Lastspitze, wenn ein Simulationsschritt länger als die Hälfte seines Zeitbudgets dauerte oder die CPU über 80 % lag (gestrichelte Linie). Den Client, an den in einer Spitzen-Minute die meisten Daten gingen, nennt das Server-Log (docker compose logs).

    Karten (Karteneditor)

    –

    Spieler mit Berechtigung schicken Karten aus dem Karteneditor des Spiels („An Server senden“). Die aktive Karte sehen alle Spieler sofort. Sie ist nur Kulisse: Stationen, Kristalle und Piraten bleiben, wie sie sind. Jeder geschlossene Monorail-Kreis bekommt einen Zug. Einsatzkarten sind keine Mondkarte: Freigegebene stehen den SG-Teams im Command Center als Ziel zur Wahl, jedes Team bekommt dort eine eigene Welt.

    Events

    –

    Ein Event legt für einen Tag oder einen Zeitraum fest, welche Einsatzkarten die SG-Teams im Command Center wählen können: zusätzlich zu den freigegebenen, oder gesperrt, obwohl sie freigegeben sind. Die Mondkarte ist immer wählbar. Gelten mehrere Events am selben Tag, zählen alle zusammen; gesperrt geht vor. Es gilt das Datum des Servers, höchstens 20 Einsatzkarten auf einmal.

    Sperren

    –

    Ein gesperrtes Konto kann sich nicht mehr anmelden. Von einer gesperrten Adresse ist gar keine Verbindung möglich, also auch kein neues Konto. Wer gerade verbunden ist, wird sofort getrennt und sieht im Spiel den Grund und die Dauer. Viele Anschlüsse bekommen regelmäßig eine neue Adresse, und manchmal teilen sich viele Kunden eine: Adressen daher lieber nur für einige Tage sperren.
